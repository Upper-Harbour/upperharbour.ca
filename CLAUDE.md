This is a static HTML site for upperharbour.ca hosted on GitHub Pages. The main database is assets/saas-db.js containing 693 SaaS tools. Stats from this DB appear as hardcoded fallback values in span elements across 23+ HTML files. Key stat IDs include ixToolCount, ixBrowseCount, heroTotal, and paperToolCount. When the database changes, these fallback values must be updated to match. The site uses no frameworks - just vanilla HTML, CSS, and JS.
